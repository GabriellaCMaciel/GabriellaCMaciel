## ✧ Sobre mim

Sou **UX/UI Designer e Desenvolvedora Full Stack**, com foco em **arquitetura robusta, escalável e sustentável**. Conecto **experiência do usuário, lógica de negócio e engenharia de software** para criar produtos digitais consistentes, do layout ao backend.

Meu trabalho parte de **clareza, processo e visão sistêmica**: nada é só visual, nada é só código.

- 🎨 **Design:** prototipo e documento interfaces no Figma antes de escrever a primeira linha de código
- 🧱 **Código:** componentes reutilizáveis, lógica organizada e foco em manutenção
- 🔗 **Ponte:** traduzo regra de negócio em fluxos claros para quem usa e para quem desenvolve
